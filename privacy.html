Privacy Policy

Last updated: September 2026

Tablet Dashboard is a personal, single-user project built and operated by Zayn Raheem. It is not a public product or service, and it is not made available to, or used by, anyone other than its developer.

What data is accessed

The dashboard connects to the developer's own Google account using Google's OAuth 2.0 authorisation flow, and reads:

  • Google Tasks — the developer's own to-do list items
  • Google Calendar — the developer's own upcoming calendar events

No other Google account is ever connected to this application, and no data belonging to any other user is collected or processed.

How the data is used

Data retrieved from Google Tasks and Google Calendar is used only to display the developer's own tasks and events on the dashboard screen. It is not stored permanently, sold, shared, or used for any purpose other than displaying it back to the developer in real time.

Data sharing

No data is shared with any third party. The application has no other users, and no analytics, advertising, or tracking services are used.

Data retention

Task and calendar data is fetched on demand and shown on screen; it is not saved to a database or log. OAuth credentials (a refresh token) are stored securely as environment variables on the developer's own backend server and are never exposed publicly.

Contact

Questions about this policy can be directed to the developer via the project's GitHub repository: github.com/Zayn-Raheem/Tablet-Dashboard
